# BB365

تطبيق كمال الأجسام للكويت والخليج: أخبار، نتائج، بطولات وتوقعات.

## الملفات

| الملف | شنو هو |
|---|---|
| `index.html` | التطبيق كامل |
| `news.json` | الأخبار اللي تطلع في الصفحة الرئيسية، ويحدّثها الروبوت تلقائيًا |
| `scripts/fetch_news.py` | روبوت الأخبار: يجيب آخر أخبار كمال الأجسام من مواقع الأخبار |
| `.github/workflows/publish.yml` | يشغّل الروبوت كل 3 ساعات وينشر الموقع |
| `manifest.webmanifest` و الأيقونات | عشان التطبيق ينضاف لشاشة الآيفون بأيقونة |

## النشر أول مرة

1. Settings ← Pages ← تحت **Source** اختر **GitHub Actions**.
2. Actions ← **Publish BB365** ← **Run workflow**.
3. بعد دقيقتين يصير الرابط: `https://اسمك.github.io/bb365/`

## على الآيفون

افتح الرابط في Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

## الأندية والمتجر

حاليًا تطلع عليهم «قريبًا». الكود الكامل موجود في `index.html` باسم `clubsFull` و `shopFull`، ونرجّعه لما نتفق مع النوادي والمتاجر.
